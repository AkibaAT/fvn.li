# FVN.li Documentation

FVN.li tracks and analyzes visual novels published on itch.io, including game versions, ratings, dialogue, languages, and update notifications.

Use these guides to work with the project:

- [Development Guide](development-guide.md): local setup, builds, tests, and contribution workflow
- [Frontend Architecture](frontend-architecture.md): Svelte, Inertia, shared layouts, and frontend organization
- [Artisan Commands](commands-overview.md): the documented maintenance and import commands

The application is available at [FVN.li](https://fvn.li). Source code and contribution details are in the repository's root `README.md`.
